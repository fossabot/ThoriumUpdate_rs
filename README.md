# [Thorium](https://github.com/Alex313031/thorium) Updater (Windows)

Based on [`template-rs`](https://github.com/just-shadyumbrella/template-rs#prerequisites).

## Usage:
- `/help`, `/?`: Show this
- `/silent`: Do not show console output.
- `/force`: Force uninstallation of existing Thorium installation if any.
  - `/clearuserdata`: Clear Thorium user profile and data as well. (Usually `%LOCALAPPDATA%\Thorium\User Data`)
- `/repo`: Override GitHub repository of Thorium update source.
- `/simd`: Force use specific CPU instruction set build.
